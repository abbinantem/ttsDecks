# High-resolution hero portraits

The square transparent PNGs in this directory are the editable portrait masters. The current layered UI exports are `../<hero>-v3.png`, selected by Game Turn Control in TTS_scripts. Keep these masters and the current v3 exports.

Superseded v2 exports in the parent directory were removed during repository cleanup. `archive/` preserves the earlier Clovis teeth and Silas framing references; prompts, reference art and validation records document how the masters were made. Historical validation files may describe retired v2 exports and earlier master revisions. `ui-v3-validation.json` records the current UI export checks.

Clovis has the corrected human teeth; Silas uses the requested head-only framing. Both current masters are 1254 × 1254 RGBA. The UI exports reduce the portrait onto a transparent 516 × 258 canvas.
