# Warrior — Tabletop Simulator package

Import via Objects > Components > Custom > Model:

- Mesh: `warrior_tts.obj`
- Diffuse: `warrior_tts_diffuse.png`
- Normal: `warrior_tts_normal.png` (optional)
- Collider: `warrior_tts_collider.obj`
- Type: Figurine
- Non-Convex: disabled

Direct asset URLs start with:
`https://raw.githubusercontent.com/abbinantem/ttsDecks/main/models/warrior/`

The triangulated mesh has 8,886 geometric vertices, 17,649 distinct vertex/UV/normal combinations and 17,988 triangles. The collider has 92 vertices and 180 triangles. See stats.json and export_validation.json for export checks. Import and physics have not been verified inside TTS.

The package includes the native Blender master, a GLB copy and a preview. Source: warrior_refined/warrior_tabletop_package. Original source files are preserved.
